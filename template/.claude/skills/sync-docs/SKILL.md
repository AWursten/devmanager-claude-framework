# /sync-docs

Pulls what a coding session needs to know out of DevManager and writes it into the repo, so that reading it costs a file read instead of five MCP calls.

**One-way, by design.** DevManager is the source of truth. Nothing here ever writes back, and the generated files are not a place to fix anything — see **When the repo disagrees** at the bottom.

`--dry-run`: do everything except write and commit; print the diff you would have made.

## Read

The project id is in `CLAUDE.md`. In order:

1. `get_context` — rigor, `responseLanguage`, `docsLanguage`, writing guide, conventions, phases, the project summary.
2. `list_documents`, then `get_document` for each. **Both audiences: INTERNAL and CLIENT.** This repo is team-side; a CLIENT document is not a secret from the team, it is a document written for a different reader.
3. `list_decisions` with the accepted ones, then `get_decision` for each.

## Write

Everything goes under `.claude/docs/`, plus the managed block in `CLAUDE.md`. **Nothing else in the repo may be touched by this skill** — not a source file, not `settings.json`, not a line of `CLAUDE.md` outside the markers.

Every generated file opens with exactly this line:

```
<!-- generated by /sync-docs — edit in DevManager, not here -->
```

### `.claude/docs/<slug>.md` — one per document

**Translated to English** (the repo's language, whatever `docsLanguage` is) and **condensed to what a coding session needs**. That last part is a judgement you have to make deliberately, so here is the rule:

- **Compresses:** the writing guide's prose niceties. Framing, motivation, the paragraph that eases a reader in, the recap of what the previous section said, anything addressed to a stakeholder rather than to a builder. A page of context becomes two sentences.
- **Does not compress:** constraints, definitions, names of things, rules, numbers, limits, enumerations, decisions already embedded in the text, anything phrased as "must", "never", "only when". These survive verbatim, in the same words. A constraint you paraphrased is a constraint you may have changed.

When in doubt about a sentence, keep it. The file is read by a session with a task in front of it: a paragraph too many costs tokens, a constraint too few costs a bug.

Keep the source's headings and order — a session that also reads the DevManager document should recognise it. Head each file with the document's title, slug, audience, type and version.

### `.claude/docs/decisions.md`

Accepted decisions only, **newest first**, `DEC-n` numbers preserved exactly — they are how people refer to them in commits and comments. Per decision: number, title, date accepted, and the three sections (context, decision, consequences), condensed by the same rule. A decision's *decision* section is a constraint; it does not compress.

### The managed section of `CLAUDE.md`

Replace everything between `<!-- devmanager:begin -->` and `<!-- devmanager:end -->`, and nothing outside them. If either marker is missing, **stop and say so** rather than guessing where the section goes.

Inside: the project summary (a few lines), the rigor level, `responseLanguage` and `docsLanguage`, the phase list, and an index of `.claude/docs/` with one line per file. Short — this is read on every single session.

## Commit

One commit, message `sync-docs: <YYYY-MM-DD>`, **only when something actually changed**. Nothing changed is the normal outcome of running this twice, and it is not worth a commit. Do not push.

If the run produced no changes, say so in one line and stop.

## When the repo disagrees with the docs

You will find contradictions: the code does X, the document says Y. Do not fix the generated file — the next `/sync-docs` would revert it, and DevManager would still be wrong.

- The **document** is out of date → offer to update it in DevManager: `get_document` for the version, `upsert_document` with `expected_version`, in `docsLanguage`, per the writing guide.
- The **code** contradicts something the project settled → that is a decision, not an edit. `propose_decision` with the three sections, and raise it with a human.
- Do not guess which one it is. Ask.
